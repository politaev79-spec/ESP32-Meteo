----------------------------------------------------------------

4. РАСПИНОВКА (АКТУАЛЬНАЯ В config.h)
----------------------------------------------------------------
- Сейчас: SDA=GPIO0, SCL=GPIO1  (перенесли с GPIO8/9 из-за LED/strapping).
- Провода на плате: SDA датчика -> GPIO0, SCL датчика -> GPIO1,
  VCC -> 3V3, GND -> GND.
- ВАЖНО: GPIO8 на плате = синий LED, GPIO9 = strapping (BOOT).
  Для I2C лучше НЕ использовать GPIO8/9 (влияют на шину).
- При смене пинов — менять BOTH config.h И физические провода.

----------------------------------------------------------------
6. ВАЖНЫЕ ГРАБЛИ (уже пройдены — НЕ повторять)
----------------------------------------------------------------
- НЕ пытаться включать ARDUINO_USB_CDC_ON_BOOT=1 или ARDUINO_USB_MODE=1:
    * USB_MODE не поддерживается C3 (нет tinyusb) -> USB не объявляется.
    * CDC_ON_BOOT ломает сборку framework (Serial не объявлен /
      serialEventRun в HardwareSerial.cpp).
- Serial по умолчанию на C3 = UART0 (GPIO20/21), НЕ на USB.
  Чтобы выводить лог в USB (COM-порт): определить свой экземпляр
  `HWCDC usbLog;` (include <HWCDC.h>) и печатать в него.
  Это НЕ ломает сборку (в отличие от переопределения глобального Serial).
- Скан I2C лучше делать ОДНИМ чистым проходом (однократный Wire.begin +
  pullup), а не многократно переинициализировать Wire по парам.
- Для пустой шины: сначала проверить питание модуля (VCC=3V3, общий GND),
  затем непрерывность SDA/SCL, затем другие пины, затем признать брак.

----------------------------------------------------------------
7. СЛЕДУЮЩИЕ ШАГИ (когда принесут исправный модуль)
----------------------------------------------------------------
1. Подключить: SDA->GPIO0, SCL->GPIO1, VCC->3V3, GND->GND.
2. Проверить COM-порт (Get-CimInstance Win32_SerialPort).
3. pio run -t upload --upload-port COM<X>
4. Прочитать лог: ожидать "AHT20 OK at 0x38" и "BMP280 OK at 0x76/0x77",
   затем периодические "[OK] T=... C H=...% P=... hPa Alt=... m".
5. Проверить Web UI: подключиться к "ESP32-Meteo", открыть http://192.168.4.1
   (температура, влажность, давление, высота).

ГОТОВЫЙ СНИППЕТ ЧТЕНИЯ USB-ЛОГА (PowerShell вызывает python из pio)
================================================================
& "C:\Users\User\.platformio\penv\Scripts\python.exe" -c "import serial,time
s=serial.Serial('COM9',115200,timeout=0.3); s.setDTR(False); s.setRTS(True); time.sleep(0.3); s.setRTS(False)
out=bytearray(); end=time.time()+10
while time.time()<end:
    try:
        d=s.read(512)
        if d: out+=d
    except Exception: break
print(out.decode('utf-8','replace'))
try: s.close()
except: pass"
